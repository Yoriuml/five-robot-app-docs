# 固定内存与资源预算 · API 2.15

16 MiB 是设备 Flash，不是应用 RAM。按最重功能组合测量资源；下列上限不是所有服务可同时运行的保证。

| 项目 | 约束 |
| --- | --- |
| WASM 模块 | 最大 96 KiB，MVP 整数指令；不提供 WASI、线程、JIT、AOT |
| 逻辑线性内存 | 一页 64 KiB，初始与最大相同、非共享、不导入内存 |
| 静态边界 | 导出只读 i32 __data_end、__heap_base；heap_base 16 字节对齐 |
| 实际物理申请 | heap_base 向上对齐至 4096；不使用 memory.size / memory.grow |
| Wi-Fi / ESP-NOW | 静态边界（含 C 栈）最多 48 KiB；其他最多 64 KiB |
| C 栈 | 示例 4096 B，可选 8192 B；避免递归和大局部数组 |
| 解释器栈 | app.json 的 stack=4096..8192，与 C 栈不同 |
| linear_memory | 固定 0，表示 WAMR host heap 配置，不表示“应用不用内存” |
| 应用包 | ≤ 8 MiB；实际可安装容量由设备剩余空间决定 |
| 事件队列 | 1..16；tick_ms=10..1000，只是目标节奏 |
| 图形场景 | gfx_submit 最多 96 条命令；单条结构 44 B |

不允许 malloc/free。大图、音频、字体和表格存资源区，有界读取。不要访问 __heap_base 之后的地址，也不要把页尾 padding 当作可用堆。

原生服务另有 RAM 开销，例如 Wi-Fi、TLS、解码器和 UI 纹理缓存。接口失败时处理错误，不能用无限重试或重启掩盖。
UI 2.15 的纹理缓存为 4096..49152 B，16 槽，每槽 ≤ 16384 B；节点最多 32 个。详见真实头文件和[扩展导航](api-extensions.md)。

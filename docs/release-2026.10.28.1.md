# SDK 2026.10.28.1

API 2.16，XAPP 包格式1。`release-ready`表示已准备冻结工件；公开可用性、目标硬件与最终固件哈希以[正式索引](https://site.flashbot5.com/developer/v1/index.json)为准。历史发行不覆盖。

- 新增版本化BLE会话、独立普通Beacon、固定远端UDP、三路明文WebSocket和只读UTC。旧API2.15及以前的导入和布局保留；新增入口要求配套API2.16固件。
- 原生PCM新增8kHz播放；16kHz采集／播放不变，8kHz采集不支持。配置扩展的版本要求高于原有PCM导入的最低版本。
- DMR 0.1.1仅为连接测试版，**不支持语音通话**。AMBE实验接口默认关闭，缺少独立互通和实时性验收，不自动启用或宣传完整DMR语音。
- FMO当前为兼容语音主机的三路WS显示／遥控／收听端；合成源测试不能代替真实FMO服务互通和人耳试听。
- 保留原来的一句话与`docs/ai-workflow.md`，由`workflow.py prepare/build`或一次源码JSON请求完成固定工具、能力上下文、资源缓存、构建与产品检查。工具不调用模型。
- 六套示例含BLE会话示例，默认使用已有合法资产缓存；自定义中文按需准备锁定HarmonyOS Sans SC，禁止Noto Sans SC。BLE示例复用starter资产，不重复携带完整中文字体。

SDK检查分别记录文档／快照、Python负例、六模板实编译、最终包静态复验及主机状态测试；它们不能证明目标设备的声音、联网互通、射频或帧率。最终整机UI与设备服务由维护方另行验收。

公开包包含声明、工具、文档、示例和测试，不包含私有固件／宿主模拟器、网站凭据、数据库或OTA密钥。服务器模拟器和AI生成上下文须绑定本发行的113个导入、真实结构与最低版本；不支持的能力明确报错，不用桩成功冒充真实网络／蓝牙／音频。

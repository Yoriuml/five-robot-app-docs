# 测试与交付

## 本机构建

运行 tools/build.py、xapp_tool.py inspect、仓库 tests。记录工具版本、包 SHA-256、WASM 大小与物理内存估计。
本仓库只提供静态与 WABT 校验、示例桩测试，不提供私有 WAMR 宿主。不能把 Python 打包或 WABT 成功写成真实运行时通过。

## 设备验收

- 安装成功后，不重启即可在列表找到并启动。
- 每个页面的短按、长按、连按和松手没有重复动作，明确的退出入口始终可用。
- 连续进入/退出至少 20 次，检查资源能否释放。
- 如有音频/网络，测试断网、超时、资源不足和服务冲突；声音与显示由实机判断。
- 应用私有数据保存、读取、清空符合说明。
- 使用最重资源组合持续运行，记录设备固件版本、时长、实际现象和错误。

## 交付清单

源码、app.json、.xapp、validation.json、包 SHA-256、按键说明、最低 API、权限用途、已测/未测项。
修复后更新版本。安装器不会因为你写了“测试通过”就跳过设备校验。

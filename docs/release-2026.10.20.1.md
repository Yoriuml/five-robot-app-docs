# SDK 2026.10.20.1

API 仍为 2.15，XAPP 包格式仍为 1。公共头文件和 api.json 与前一发行逐字节一致；api.json 中的发行号表示 API 快照来源，详见 SDK-SNAPSHOT.json 的 api_snapshot_release。

本发行将开发流程约束集中到 [AI 执行契约](ai-workflow.md)，由 AGENTS.md、README 和 llms.txt 引导读取。

## 改进

- 五个模板都包含启动器图标、中英文名、合法字体子集和原生缓存，新增 native-ui-audio 的双轨 PCM 示例。
- create_app 支持中文展示名、完整 OFL 字体输入、改名子集和可移植缓存；缺字或错误资产明确失败。
- 产品按键帮助层适配中键动作、左键返回，保留历史 ABI；模板包含启动松手、首屏、错误与退出清理路径。
- build 默认执行最终包产品检查；validate --product 和独立 check_product 复验名称、图标、字形、资源、必要导出及包哈希。旧包通用校验保持兼容。
- 跨 SDK 工具缓存按平台、版本、官方归档哈希隔离，支持进程锁、离线、镜像校验、下载超时、失败回滚和阶段耗时。
- 可选 Python 依赖以 wheel 哈希锁定并隔离安装；默认模板无需这些依赖。完整公开中文字体与许可证可按哈希一次下载并缓存。

## 验证记录

发布前已执行 tools/test_sdk.py：45 项 Python 检查、五模板真实 WASM 构建、独立 WABT/产品验包、六组原生 C 状态测试通过。

维护者另用授权的生产原生渲染器只读测试 SDK C 模板：可见首屏、100 次局部导航、静止零传输、资源不重复读取和退出测试堆回收通过。该测试不执行最终 WASM，不公开生产源码。

真实工具归档冷准备和第二 SDK 目录的离线共享复用均已通过。公开 Noto Sans SC 字体及许可证下载哈希、许可检查、自定义中文名创建与禁止导入 Pillow/fontTools 的后续构建通过。

本发行不含目标设备烧录、听感、帧率、TLS 并发峰值或真机稳定性测试；这些层级保持未测。网站预览与服务器复验按各自报告记录，不由 SDK 本地结果代替。

先部署[测试站](https://site.flashbot5.cn/developer/v1/index.json)，生产站索引是否更新以实际部署为准。GitHub、Gitee 与服务器应使用 release-ready.json 记录的相同提交、不可变标签和文件 SHA；不能覆盖历史发行。

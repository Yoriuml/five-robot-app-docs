# C3 内存、调度、帧率与资源预算

专题 ID：`performance`。有动画、联网、声音或内存错误时读取。16 MiB Flash 不等于可用 RAM；不同固件配置和初始化顺序下的空闲内存不同，没有固定的“保证可用堆”数字。

## 先算最重组合

峰值应包含：全局／静态区、任务栈、屏幕 DMA、GUI 工作集、解码暂存、Codec／I²S DMA、Wi-Fi／BLE、TLS、网络响应与队列。共享内存池不能重复按各自全部空闲相加。中间状态也算峰值，例如旧纹理未释放时加载新纹理、重连时旧请求尚在退出。

| 数据 | 载荷公式／例子 |
| --- | --- |
| RGB565 | `w×h×2`；全屏 115,200 B |
| A4 遮罩 | 连续紧密布局为 `ceil(w×h/2)`；有行跨度的格式另算 |
| DMA 条带 | `240×rows×2`；40 行 19,200 B |
| PCM16 单声道 | `sample_rate×2×seconds`；16 kHz 100 ms 为 3,200 B |
| 有界队列 | `元素数×单元素存储`，另加队列元数据和所有者引用 |

图片压缩降低 Flash／传输大小，不自动降低解压峰值。高压缩整帧图在设备上每帧解压可能更慢；字库、JPEG、JSON 大对象、整段录音均应分块或限制上限。

## 该记录的指标

在冷启动、显示完成、无线启动、TLS 前后、音频启动、最重页面和退出后记录：

- `heap_caps_get_free_size(MALLOC_CAP_8BIT)`：相应能力的空闲堆总量。
- `heap_caps_get_largest_free_block(...)`：相同能力的最大连续块，不能用总量代替。
- DMA 用 `MALLOC_CAP_INTERNAL | MALLOC_CAP_DMA` 单独记录；不要把不同 heap 统计相加当物理总 RAM。
- `heap_caps_get_minimum_free_size(...)`：低水位；任务用实际 IDF 的栈高水位接口，并标清单位，不套用其他 FreeRTOS 端口的字节／word 假设。
- 关键分配的用途、大小、失败错误，以及当前服务状态。日志限频，避免诊断本身把 UART／CPU 塞满。

静态部分用 `idf.py size` 和 map 文件分析；它们不包含全部运行时堆与任务峰值。参见 [IDF 内存能力](https://docs.espressif.com/projects/esp-idf/en/latest/esp32c3/api-reference/system/mem_alloc.html)。

## 分配与生命周期

大缓冲尽早、按需且有界申请，使用完释放；不在逐帧／逐音频样本路径 malloc／free。DMA 条带先预留，避免之后只剩碎片。不要同时保留整页图、多个解压副本和全屏双缓冲。

所有组件有单一 owner／共享租约、启动状态、取消令牌和逆序清理。禁止一个客户端退出就释放别人仍使用的 I²C／I²S／Wi-Fi。停止先禁止新回调，再取消工作，确认不再访问对象，最后释放；晚到的回调通过代次丢弃。

内存不足应减少工作集或退回低资源方案，显示明确可恢复的状态。不能静默提高限额、关闭校验、在 OOM 路径继续使用空指针，或反复重启直到碰巧成功。

## 任务和锁

C3 只有一个应用 CPU 核，不能假定把 UI 固定 core 1 就解决卡顿。事件／回调保持短小，重工作交给有限任务和队列；不要每条消息创建一个任务。UI、网络与音频都需要可调度时间，优先级不能靠“全部调最高”解决。

音频生产／消费在独立路径持续供给，UI 帧可以丢过时帧；输入松开／停止事件不能随便丢弃。用有界等待，不能在音频实时路径等 TLS、Flash 擦除或 GUI 锁。ISR／定时器回调不做阻塞 I²C／网络／文件写入。

统一锁顺序，控制总线 → PCA 状态 → 驱动；持锁期间不等待网络、PCM 队列、另一个任务的完成事件。异步 DMA 缓冲必须一直有效到完成，不“发出后立即释放”。

## 流畅度验收

用单调时间推进非线性插值，缓存下一状态所需资源；旧帧来不及显示就跳到当前状态，不追赶积压帧。测最重场景的帧间隔分布、最差停顿、输入延迟和音频欠载，而非只报平均 FPS。

UI 先保主要对象／数字的完整动画，减少背景重绘、阴影、大面积 alpha 和资源重载。静态页不持续全屏刷新；按键高亮先局部呈现。网络重连／音频切换要测试与动画同时发生的情况。

至少覆盖冷／热启动、反复进入退出、最重页面、长文本、最大资源、网络失败、快速按键和停止重入；测试数量由改动决定，不为纯换文案跑全套硬件回归。桌面预览只能验证布局／状态，不模拟 C3 全部带宽、碎片、DMA 或声学结果。

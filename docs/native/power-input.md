# 电源、四键、电池与启动

专题 ID：`power-input`。新工程必读。数值为现有系统的软件行为基线，独立固件可以按产品需求调整手势，但不能破坏保持电源、BOOT 和板型接线合同。

## 最小启动状态机

`复位 → 建立 I²C → 安全初始化 PCA → 判定供电／开机 → 确认 IOEN → 初始化显示／输入 → 首屏 → 按需业务`。

1. 创建 I²C0 master bus：SDA0、SCL1、默认时钟源，设备速度 400 kHz。使用 IDF 当前 master 驱动，不与旧 I²C 驱动在同控制器混用；内部上拉不能替代实际外部上拉的电气验收。
2. 添加 `0x19` PCA。读取旧方向与旧输出；若 IO1 原本为输出且为高，保留高电平。旧状态读取失败必须记录，不假定是全零；对电池热重启的连续供电不作无证据保证。
3. 先将“旧方向 OR 本板输入掩码”写入方向寄存器，释放应为输入的脚；写安全输出 `0x20 | 已有有效保持位`，写极性 0，再写最终方向 `0x0D`／`0x05` 并读回。
4. 在合法开机条件成立后，掩码置 IO1＝1 并读回。其他任务更新 DC／CS／RESET／背光时绝不能清掉 IO1。
5. PA GPIO13 保持低，初始化屏幕，绘制完整可见首屏后开背光。电池采样失败不阻止本地首屏，网络不阻止主界面。

I²C/PCA 更新应串行化，递归总线控制门 → PCA 状态锁 → I²C 驱动，统一顺序；不要在 ISR 中调用。任何初始化阶段失败，清理本阶段资源，记录阶段和错误，避免无界复位循环。

## 冷启动、热重启与 USB

- 电池冷启动：现有产品按 K1 约 1 秒锁住 IO1，持续约 2 秒进入完整系统；过早松手不进入完整启动。做新产品时可以改变手势，但启动必须在临时上电窗口内建立电源保持。
- USB 存在由 PCA IO2 高电平决定。现有基线在最多 150 ms 的判定窗口内使用间隔 30 ms 的稳定采样；稳定 USB 可直接开机，不要求用户一直按 K1。
- 热重启不能通过短暂清 IO1 把自己断电。读取并保留既有输出方向／锁存很关键，不能只靠启动默认值。
- 启动时已经按住的键，要等松开才接受普通动作，避免首屏立即触发确认／返回／关机。恢复唤醒也要处理。

## 四键与非阻塞输入

物理键与 GPIO 见 [hardware](hardware.md)。所有键低有效、上拉。推荐轮询或 ISR 通知后由任务处理，扫描节拍与消抖分离；例如 5～10 ms 扫描、20～30 ms 稳定状态是实现起点，需实机调优，不是硬件固定值。

每键保存 raw／stable 状态、变化时刻、按下时刻、长按是否已消费。发出 press、release、hold／repeat 事件；不能通过 `while(按住)` 阻塞任务。长按已消费后不再补发短按。事件队列有界，不让重复事件挤掉松开事件。

默认产品语义：中键主动作，左键返回，上下选择或调整；有按下和松开反馈。录音／电键等需求从 press 开始，release 结束，不应等短按事件才启动。普通 UI 手势与电源长按分开仲裁。

现有系统参考阈值：左键长按 500 ms 返回主页、2 秒关机、6 秒应急关机。这些是软件策略；不要从历史 README 的 1.5／20 秒复制旧值。独立固件没有官方桌面时应定义自己的返回层级。应急退出不能把未完成的 Flash 操作伪装成成功。

## 有序停止与关机

先拒绝新业务 → 取消网络／收发 → 停音频并 PA 拉低 → 等待或取消显示 DMA → 关背光、LCD RESET 拉低 → 按 USB 状态选择待机或释放电源。

- 电池供电：清 IO1 并读回；仍运行时进入适合本板的低功耗等待／唤醒路径。唤醒脚能力和电路按目标芯片配置核对，不能照搬其他 ESP32 的 RTC GPIO 示例。
- USB 供电：清 IO1 不保证物理断电，应该进入明确的关机待机；不要反复 `esp_restart()`，也不要把充电页当主界面重启。
- 关闭或深睡前，避免持有 I²C／文件系统锁、留下功放开启或 DMA 仍访问已释放缓冲。

## 电池与充电

电池 ADC 为 GPIO3、ADC1 CH3，分压 100 kΩ／100 kΩ。使用校准后 ADC 引脚电压×2。现有实现读取前丢弃一次转换，采 10 次取中位数，2.4～4.6 V 以外标记无效；校准创建失败也标记无效，不用原始计数冒充电压。

采样频率只需满足 UI 更新，不逐帧采样。电量百分比是电压经验估计，受负载影响，不是精密库仑计。电池容量和续航需要实际电池型号与测量，本文不提供虚构数值。

USB IO2＝外部电源存在；充电信号 v1 IO3／v2 IO0＝充电状态软件约定。输入极性和充满表现要实物核对，不能仅凭一个电平宣称充满或电池故障。

# 屏幕、字体与流畅 UI

专题 ID：`display-ui`。需要任何设备画面时读取。本页为独立驱动合同；XApp 的 `ui_texture`／`ui_scene` 只适用于官方运行时，不在这里调用。

## 屏幕初始化与事务

ST7789，240×240，SPI2、Mode 0，请求 80 MHz，MOSI5／SCLK4，无 MISO。初始化时记录实际 SPI 时钟；设备的硬件 CS 参数设未使用，由 PCA9557 IO5 控制。DC＝IO4、RESET＝IO6、背光按板型。扩展 IO 的方向和锁见 [hardware](hardware.md)。

参考启动顺序：

1. 关背光，RESET 拉低，等待至少 10 ms。
2. RESET 拉高，等待 120 ms。
3. 发 `0x01` 软件复位，等待 120 ms；发 `0x11` 退出休眠，等待 120 ms。
4. `0x36`＋`0x00`（MADCTL）；`0x3A`＋`0x05`（COLMOD）；`0x21`（反色开启）；`0x29`（显示开启）。
5. 画完整首屏，完成传输后开背光。延时必须真正让出 CPU，不能转成 0 tick。

窗口使用 `0x2A`（列）和 `0x2B`（行），起止坐标大端、两端包含，范围 0..239。随后 `0x2C` 开始像素流；即便复用前一次窗口，也不能省掉重新开始像素写入的 RAMWR。无把握的传输后使窗口缓存失效。

一次完整窗口＋像素事务保持 CS 选中，命令 DC 低、参数／像素 DC 高。SPI DMA 完成前不改 DC／CS、不复用／释放像素缓冲；结束才拉高 CS。事务期间统一 I²C 控制锁，不能一边 Codec 改总线、一边另一个任务覆盖 PCA 输出影子。

RGB565 数值与 SPI 字节流分清：例如红 `0xF800` 在线路发送 `F8 00`。小端主机的 uint16_t 数组可能需要交换字节；整个路径只交换一次。先画纯红、绿、蓝、白及四角标记，确认字节序、反色、边界与方向，不用随机改 MADCTL 掩盖接线错误。

## 缓冲与刷新

240×240×2＝115,200 B；全屏双缓冲＝230,400 B，不能作为 C3 默认方案。可使用内部 DMA 条带：8 行 3,840 B、20 行 9,600 B、40 行 19,200 B。`max_transfer_sz` 必须覆盖实际单次提交尺寸；条带总量、队列深度和 UI 临时内存一起预算。

DMA 缓冲用适当的内部 DMA 能力内存分配并检查结果；资源源图可留 Flash，但不能把任意 Flash 指针当作所有 DMA 配置都可直接访问的缓冲。具体分配和硬件限制以所用 IDF 头文件为准，参见 [IDF 内存能力说明](https://docs.espressif.com/projects/esp-idf/en/latest/esp32c3/api-reference/system/mem_alloc.html)。

合并相邻脏区，在条带中渲染；不要每像素改一次 PCA。屏幕传输由一个任务拥有。队列有界，不累计已经过期的 UI 帧；需要等待音频／网络时释放屏幕控制锁。超时重试只对已确认可重试的错误，重新发完整窗口和同一批像素，设置次数上限；NACK、参数错误、OOM 不无限重试。

## LVGL 可选接法

需要 LVGL 时使用配套 9.5 API，不能混用 8.x 显示注册示例。使用部分刷新缓冲，flush 回调通过实际 PCA 传输层送条带；DMA 完成后再报告 flush ready。不能先 ready 再继续异步读取该缓冲。

LVGL 对象更新由一个 GUI 任务或统一互斥保护；网络／音频回调只投递状态，不直接修改对象。tick／定时器使用单调时间。屏幕旋转、输入焦点与布局一起调整，不能只交换宽高。

## 视觉与中文

默认中文，优先清晰的大主体和必要状态；不自动加操作说明、长副标题、装饰性标签。用户指定参考时先还原比例、层级、字重与交互，不把“换色”当重构。鲜艳色可集中于主色或反馈，正文与背景必须保持对比。

中文使用许可允许的 HarmonyOS Sans SC 或指定字体，提供来源和许可证，按实际字形裁剪。不用 Noto Sans SC 或其别名；缺字不得静默回退。数字单独处理字宽、对齐和大字号观感。字体／文字遮罩由电脑生成，设备不每帧排版栅格化整页。

遮罩数据按自己的渲染器明确定义尺寸、行跨度、位序与 alpha 混合。不要把 XApp 的 A4 协议自动套给 LVGL 或另一套原生纹理格式；格式转换应由资产生成器完成。字图尺寸、裁剪坐标和有效载荷长度需验算。

## 非线性动画

用真实经过时间计算 `t=clamp((now-start)/duration,0,1)`，比如 ease-out cubic `1-(1-t)^3`；按下、松开、切换分别定义起点与目标。中途反向操作从当前呈现状态继续，不跳回初始帧。避免每次按键重建整个页面。

卡顿后跳到当前时间对应状态，不补跑几十帧旧动画。图片解码、字形加载、网络连接和 Flash 写入不放在动画关键路径。秒表／时钟变化先预热下一数字资源，不能每秒发生一次大分配导致只看见动画最后一抖。

静态页停更或低频更新；动画页只刷新变化区域。目标帧率根据真机最重场景测定，不承诺桌面 60 FPS 即设备 60 FPS。进一步预算见 [performance](performance.md)。

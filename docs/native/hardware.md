# 硬件合同

专题 ID：`hardware`。适用资料版号：`native-2026.10.30.1`。新工程必读；具体电源时序见 [power-input](power-input.md)。

## 平台与能力

ESP32-C3，单核 RISC-V，160 MHz；外置 P25Q128，128 Mbit＝16 MiB Flash。按片内 RAM 设计，不假定有 PSRAM。屏幕 ST7789 240×240，RGB565；音频 ES8311，I²S 数字接口；PCA9557 提供电源与屏幕控制。

支持 2.4 GHz Wi-Fi 与 BLE。不能把 ESP32 的经典蓝牙能力套到 C3：不提供 Bluetooth Classic SPP／A2DP。没有在本合同中确认的触摸屏、SD 卡、外置 RTC、IMU、蜂窝或 GNSS，不能凭需求自行假定存在；需要时使用网络、现有按键或另行确认硬件。

## 共有 GPIO

| GPIO | 网络／用途 | 方向与要求 |
| --- | --- | --- |
| 0 | I²C SDA | PCA9557＋ES8311，共用总线 |
| 1 | I²C SCL | 400 kHz |
| 2 | K1，左键／电源 | 输入，上拉，按下为低 |
| 3 | 电池 ADC | ADC1 CH3，100 kΩ／100 kΩ 分压 |
| 4 | LCD SCLK | SPI2 输出 |
| 5 | LCD MOSI | SPI2 输出，无 MISO |
| 6 | I²S DOUT | MCU → ES8311 |
| 7 | I²S DIN | ES8311 → MCU |
| 8 | I²S BCLK | MCU 主机时钟输出 |
| 9 | K4，上键／BOOT | 输入，上拉，按下为低；启动绑带脚 |
| 10 | I²S MCLK | MCU 输出，通常 256×采样率 |
| 11 | VDD_SPI | 保留，不用于 PWM／普通输出，见下文 |
| 12 | I²S WS | MCU 输出，采样时钟 |
| 13 | 功放使能 | 输出，高有效，启动先低 |

信号按现有 3.3 V 逻辑设计，不将外部 5 V 直接接到 GPIO。USB 存在检测是 PCA IO2 的分压信号，不能把外部 VBUS 当成可直连 MCU 的数字信号。

## 编译期硬件分型

| 项目 | `ch343-v1` | `native-usb-v2` |
| --- | --- | --- |
| K2，中键 | GPIO19，低有效上拉 | GPIO21，低有效上拉 |
| K3，下键 | GPIO18，低有效上拉 | GPIO20，低有效上拉 |
| USB 数据路径 | CH343P → UART0 | USB Serial/JTAG |
| UART0 TX／RX | GPIO21／GPIO20 | 业务不启用，二脚属于按键 |
| USB D+／D− | 不在应用阶段启用，二脚是按键 | GPIO19／GPIO18 |
| PCA 输入方向掩码 | `0x0D`：IO0、2、3 | `0x05`：IO0、2 |
| 充电检测 | IO3，软件低有效 | IO0，软件低有效；实物极性待核对 |
| 背光掩码 | `0x80`：IO7 | `0x88`：IO3＋IO7 |
| 参考 USB VID:PID | `1A86:55D3` | `303A:1001` |
| 官方系统 OTA model | `x622-c3-16m-staged2` | `x622-c3-16m-staged2-usb` |

CH343 TXD → MCU RX20，CH343 RXD ← MCU TX21。COM 号由电脑分配，不能固定，更不能当板型标记。VID/PID 只辅助识别传输路径，同类芯片的其他设备也可能枚举相同标识。

用一份业务源码和编译期板型表，隔离 GPIO、控制台与背光方向；板型变化必须换构建目录和 sdkconfig。用户未指定时生成两种目标，不扫描／驱动相互冲突的脚猜硬件。

新板 GPIO21 仍有 ROM UART TX 行为。切换应用控制台不能消除 ROM 输出；按住相应键上电的限流／电气安全以实物电路为准。GPIO2、8、9 涉及启动绑带行为，不额外加载改变上电电平的电路。

## PCA9557

I²C **7 位地址 `0x19`**；寄存器：输入 `0x00`、输出 `0x01`、极性 `0x02`、方向 `0x03`。方向位 1＝输入；极性寄存器为 `0x00`。

| IO | 用途 | 有效电平 |
| --- | --- | --- |
| 0 | v1 未连接；v2 充电检测 | 始终输入，勿驱动 |
| 1 | IOEN 电源保持 | 高保持开机 |
| 2 | USB 5 V 存在检测 | 输入，高有效 |
| 3 | v1 充电输入；v2 第二路背光 | 方向按板型 |
| 4 | LCD DC | 低命令，高数据 |
| 5 | LCD CS | 低选中 |
| 6 | LCD RESET | 低复位 |
| 7 | LCD 背光 | 高开启 |

输出寄存器用软件影子和锁做掩码更新；**不能从输入寄存器推导输出状态**。默认安全输出 `0x20`（CS 高），但重启时必须保留原本有效的 IO1 高电平，不能先写默认值再补保持。完整流程见 [power-input](power-input.md)。

LCD DC／CS／RESET 不是 MCU GPIO。不能向 `esp_lcd` 普通 GPIO 参数填 PCA IO4／5／6，也不能把它们改到其他脚。音频 Codec 和 LCD 控制共享 I²C，使用一致的总线所有权和锁顺序。

## 不可擅改的电气事项

GPIO11／VDD_SPI 当前悬空且 Flash 独立供电。只有芯片已配置 `VDD_SPI_AS_GPIO` 时，才按已确认实现关闭其 GPIO 输入、输出、上下拉；未配置时不碰这个电源复用焊盘。开发程序不烧 eFuse，不将 GPIO11 作为背光 PWM。

旧板背光仅数字开关；新板双路输出仅离散组合，不承诺连续 PWM 亮度。充电输入不是第二路背光，USB 存在也不是“正在充电”。物理按键位置若与 PCB 标号不符，用实物确认，不能按旧 XApp 的 CONFIRM／BACK 名字猜位置。

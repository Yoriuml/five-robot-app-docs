# 网络、蓝牙、电脑连接、时间与存储

专题 ID：`network-storage`。仅在相应能力被使用时读取；硬件基础见 [hardware](hardware.md)。

## 共同生命周期

以状态机管理 `未创建 → 启动中 → 可用 → 停止中 → 已释放`。每个异步请求有代次／取消标记，退出后到达的回调不能访问旧页面或已经释放的缓冲。重试、超时、响应体、事件队列均设上限；失败时保留可用的离线页面。

Wi-Fi、BLE、网络与音频在需要时创建，最后一个使用者退出后再释放；应用退出不直接销毁另一个模块仍使用的共享资源。独立固件的 manager 需自行实现，不调用不存在的官方系统服务或 XApp 宿主 API。

## Wi-Fi 与 HTTP／HTTPS

使用 2.4 GHz 网络；扫描结果与凭据有界存储。先收到 IP 事件，再开始依赖 IP 的请求；连接 AP 不等于 DHCP／DNS 已成功。支持用户配置网络，不把开发者 SSID、密码、IP 或 COM 号固定给所有客户。

HTTP 处理状态码、重定向次数、Content-Type、Content-Length／分块传输、断开与超时；JSON 限定总长度、嵌套与数组数量。接口 URL、鉴权、缓存期限和错误合同要有实际来源，不在生成时虚构可用服务。

HTTPS 保留证书与主机名验证。核对系统时间、根证书包、证书链和算法配置、实际连续内存；`signature verification failed` 不自动等于缺根证书，更不能只看一个错误码就断言根因。保留 native／transport 错误和握手前后的内存记录。

当前系统 IDF 配置包含交叉签名验证支持；在相同 IDF 能力下，核对 `CONFIG_MBEDTLS_CERTIFICATE_BUNDLE`、`CONFIG_MBEDTLS_CERTIFICATE_BUNDLE_CROSS_SIGNED_VERIFY` 及其依赖 `CONFIG_MBEDTLS_X509_TRUSTED_CERT_CALLBACK`。名称以实际 6.1 Kconfig 为准；如果所用版本不提供该选项，不伪造配置。启用交叉签名支持仍是正常验签，不是跳过验证，也不是所有证书失败的万能修复。

Wi-Fi 驱动缓存、TLS 记录缓冲、JSON 和解码器会同时占 RAM。按工作集选缓存，先测最重组合；不能把握手改成不验证、无限重试或扩大所有池子来“修复”。需要服务器聚合／转码时，应提供实际接口合同和部署物，不能假定厂商服务器已支持。

## BLE

C3 支持 BLE，**不支持 Classic SPP／A2DP**。按目标功能使用 IDF 支持的 BLE host／controller；不要同时初始化两套 host。GATT 的服务 UUID、特征 UUID、读写／通知方向、包格式、分片、MTU、连接间隔、重连和权限应成对定义并交付电脑端代码。

广播不等于连接，扫描到设备不等于 GATT 已连接；通知必须在对端订阅后发送。链路加密和配对依产品需求设置；只绑定用户授权的设备，不记录或公开配对密钥。应用可做自有 UUID、有限频率的普通 Beacon 测试，不把通用广播接口解释成能任意冒充系统协议或完成未验证的特殊功能。

可用带宽受 MTU、通知数、连接间隔、手机／电脑协议栈及 Wi-Fi 共存影响。用序号和长度校验，有界队列和背压；断连撤销旧连接句柄，重连后重建订阅状态。实时音频需测端到端，不因单帧能发送就承诺流畅。

## 与电脑连接

| 传输 | 适用 | 交付要求 |
| --- | --- | --- |
| 局域网 UDP | 低延迟音频／遥测 | 可配置地址或发现协议、端口、序号、丢包统计、有界抖动缓冲 |
| TCP／WebSocket | 可靠消息／控制 | 消息边界、断连、重连、长度上限、双端协议版本 |
| BLE GATT | 无局域网的近距离控制／数据 | UUID、特征、MTU 分片、订阅、超时和实际吞吐 |
| CH343 UART／原生 USB 串行 | 调试与有线数据 | 按板型选择后端，枚举实际设备，二进制与日志分流 |

电脑默认从实际网络适配器选择地址，不优先把 VPN／虚拟网卡 IP 写给设备。监听服务明确绑定地址，防火墙放行范围最小；只在用户授权后调整系统设置。局域网同名 SSID 不保证设备互通，需排查 AP 隔离、不同网段与访客网络。

CH343 UART 波特率必须两端一致；原生 USB Serial/JTAG 的 line coding 不等价于 UART 物理速度。端口占用时报告占用阶段，不强杀其他任务、不反复开关 DTR／RTS。二进制传输带帧头、协议版本、长度与 CRC，读取允许拆包／粘包。配套 EXE／脚本需要完整依赖、启动方式和可保存的运行日志。

## 时间与本地存储

无本合同已确认的外置电池 RTC。在线用 SNTP／明确时间服务校时，内部统一 UTC，UI 按用户时区转换；显示未校时状态，不能把运行毫秒数当年月日。秒表、超时与动画使用单调时钟，不能因系统校时回拨出现负数。

小配置用独立命名空间的 NVS，资源用自己的只读 Flash 数据或显式分区；需要 LittleFS 时显式定义分区和挂载。**挂载失败不自动 format**，先区分版本不匹配、分区错误、损坏和空白设备。设置版本化、CRC／校验及原子更新，写入合并限频；不逐帧写 Flash。

不覆盖官方系统的 Wi-Fi 凭据、设备身份、主题、应用和 OTA journal。日志隐藏密码、token、密钥和录音正文；用户数据的保存／上传按明确需求，取消和退出停止采集与传输。

# SDK 2026.10.29.1 / API 2.16

这是公开 SDK 的文档与发行元数据修订，不新增 API，不替换历史包，也不代表发布新的设备固件。

## 与 2026.10.28.1 的差异

- 增加 docs/native-firmware-ai.md：用户明确要求独立 ESP-IDF / BIN 固件时，先按双硬件合同和原生交付流程开发；native-ui 模板仍属于 XApp。
- README、AGENTS 和 llms.txt 补齐原生固件开发入口。
- SDK 发行号和标签更新到 2026.10.29.1。API 2.16 快照保持 2026.10.28.1，api.json、公开头文件、所有示例和构建工具字节不变，SDK-SNAPSHOT.json 明确记录两者。
- 旧版 SDK、ZIP、SHA、标签与固定链接保持不变；新发行完整验收后再切换最新索引。

## 验收边界

发行包 SHA、解压后样例构建、独立产品检查和网页运行证据随维护方交接记录提供。静态、主机、网页和设备验收分别记录；本文不把它们相互替代。配套设备需支持 API 2.16；实验 AMBE 仍默认关闭，不因此承诺语音通话或发布任何固件。

# API 2.16 正式合同与开发入口

API 2.16 已由官方网站索引公开提供。当前 SDK 修订是否已上线，请读取 [正式站发行索引](https://site.flashbot5.com/developer/v1/index.json)，固定其中的 sdk_release、ZIP、SHA、模板和文档；不要从旧开发快照、源码版本或历史发行准备文档推断线上版本。

本修订的 SDK 发行号是 2026.10.29.2，包格式仍为 XAPP v1；公开 API 快照保持不可变的 2026.10.28.1。api.json、头文件、模板和工具与上一已发布 SDK 字节一致，SDK-SNAPSHOT.json 与服务端发行清单显式记录 API 快照来源。本修订新增正式文档入口与独立原生固件开发入口，不新增 API 或设备固件。

## 设备要求

安装前将设备更新至支持 API 2.16 的主系统，并核对所选镜像对应的硬件型号。旧 CH343 与原生 USB 硬件的系统镜像不能互换。具体固件版本和下载以官网当前固件目录为准，本 SDK 文档不宣称任何未发布固件已上线。保留 API 2.15 及以前的导入与布局兼容；新导入或配置扩展必须满足相应最低版本。

## 合同来源

- [主头文件](../sdk/xapp/x622_xapp.h)：真实声明、结构、单位、权限、生命周期和错误。
- [机器可读 API](../api.json)：113 个公开导入及其最低版本、权限和 Wasm 参数。不要编造接口或直接调用设备私有实现。
- [自动工作流](ai-workflow.md)：按所需能力返回真实声明，构建并独立校验最终包。
- [独立原生固件开发](native-firmware-ai.md)：用户明确要求 ESP-IDF 工程或 BIN 时使用；native-ui 模板仍属于 XApp。

## 2.16 能力与边界

| 能力 | 公开合同 | 开发边界 |
|---|---|---|
| BLE 会话 | ble_open，保留旧入口和布局 | 按状态和生命周期处理连接，不能把静态通过当射频或配对验收 |
| 普通 Beacon | 自有 Service UUID 与有界服务数据 | 不提供任意厂商广播、手机弹窗或 Central 扫描 |
| IP UDP | 固定远端、有界整包、来源过滤 | 先取得 Wi-Fi 租约；发送接受不代表远端收到 |
| WebSocket | ws_open / ws_send / ws_read / ws_status / ws_close | 使用公开分块、代际和关闭合同；wss 不支持时明确失败，不能静默降低安全性 |
| UTC | clock_utc 读取系统快照 | valid=0 时提示时间未就绪，不编造日期或自行启动系统无线服务 |
| 原生 PCM 播放扩展 | API 2.16 可用 8 kHz 播放；16 kHz 合同保留 | 8 kHz 是配置扩展要求，不能仅凭导入最低版本放行旧系统；按实际采样率配置 |
| AMBE 实验导入 | api.json 明确标注 experimental | 正式默认关闭，不作为已可用语音通话或常规生成能力宣传；真实互通与设备验收另行记录 |

未提供的能力须明确说明，不能借用安装器、内部 WebServer 或其他私有服务。处理 NOT_SUPPORTED、BUSY、OOM、超时和退出；不自动扩大权限。

## 验收与交付

SDK 下载完整性、解压后构建、静态 ABI/语义/产品检查、网页运行和实机验证是不同证据。联网模板保留离线可见首屏及可退出状态；网页模拟器展示本地 UI 与按键，不代替真实 Wi-Fi、BLE、语音或目标设备性能验收。具体工具链、样例构建结果与 ZIP SHA 随本修订的交接记录提供。

[历史发行准备记录](api-2.16-readiness.md)仅供追溯，不作为当前上线状态入口。

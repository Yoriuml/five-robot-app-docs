# API 2.16：发行准备与功能边界

SDK 2026.10.28.1 / API 2.16 / 包格式1。源码与发行工件先独立冻结；公开上线须通过维护方最终整机验收，支持硬件与固件哈希绑定正式索引。历史ZIP和标签不原地覆盖。旧API2.15及以前的导入、布局和16kHz音频契约保留；新入口和8kHz播放仅配套API2.16固件可用。流程见[发行规范](releases.md)。

| 能力 | 已实现契约 | 交付边界 |
| --- | --- | --- |
| BLE 统一会话 | ble_open：version1／236 B，STREAM／HID／RECORDS，保留旧入口与布局 | 旧包兼容不代表所有配对、射频和退出恢复都在最新固件实测 |
| 普通 Beacon | 自有128位Service UUID，0..8 B数据，不可连接，100..5000 ms | 不提供任意厂商广播、手机弹窗、扫描或Central；沿用独占无线租约 |
| IP UDP | 一个固定远端，512 B整包、来源过滤、四RX／四TX | 先取得Wi-Fi租约；不是ESP-NOW，发送接受不等于远端送达 |
| WebSocket | 三路ws://，合计≤12个RX槽，16 KiB消息按≤512 B块读取 | 保留opcode／FIN／偏移／代际；wss://明确NOT_SUPPORTED，不静默降级 |
| UTC | clock_utc只读系统快照 | 不创建NTP／无线服务；valid=0时不编造日期 |
| 原生PCM | 16 kHz采集／播放；API≥2.16新增8 kHz播放 | 半双工、PCM16LE单声道，采集8000始终拒绝；按实际速率与帧长预算 |
| AMBE+2实验服务 | 已有真实异步导入和有界队列，正式固件默认OFF | 缺独立互通向量、目标实时性及真实语音验收；READY不是批准，两个VERIFIED位未同时具备不得发射 |
| APP HTTP配置服务器 | 未提供 | 用设备端参数编辑器；不调用内部WebServer或安装器私有端点 |

详细结构、单位、错误和所有权以对应[公开头文件](../sdk/xapp/x622_xapp.h)为准。APP必须处理NOT_SUPPORTED／BUSY／OOM，不扩大权限或直接链接设备私有服务。主机、WAMR、受控实机与真实互通分别记录。

## 原生8 kHz PCM的最小配置片段

清单至少 `api_major=2, api_minor=16`，声明AUDIO_PLAYBACK。完整离线首屏之后、通过状态机仅启动一次：

```c
x622_audio_stream_config_t cfg = {X622_STREAM_PLAYBACK, 8000, 800, 50};
int32_t rc = x622_pcm_playback_start(&cfg, sizeof(cfg));
```

这只是配置片段，不是完整应用。检查负错误；接受后通过pcm_status确认状态。STARTING可预填现有四帧，每次pcm_write精确1600 B，数据已被复制才推进源读指针。FULL(-9)在后续tick重试；不得循环忙等、覆盖旧帧或每条网络消息补零。退出／切换时停止并清理旧会话，半双工变更方向前先stop。进口最低版本仍为2.7，8 kHz配置扩展另要求2.16，不能只依据api.json里pcm导入的最低版本。

对于原生8 kHz输入，不在WASM中额外上采样到16 kHz。16 kHz采集／播放和旧APP行为保持；本地resource／track等其他音频家族的格式不因这个扩展自动改变。四帧队列的时间容量随frame_samples而变，不承诺所有帧长／UI／网络组合都不卡顿。预算见[内存配置](memory-profile.md)。

网络PCM-only模块在配套固件的既有网络音频预留分支内，可跳过实际未使用的MP3解码器／输入输出缓冲，仍预留TX DMA。判据是API≥2.16、真实pcm_playback_start导入且没有media_play，并满足既有非BLE／ESP-NOW条件；旧API、混合媒体和不确定模块保持完整预留。没有新增APP开关，不能故意删除需要的导入来规避预算。

## 候选应用与证据范围

FMO是兼容语音主机三路WS的显示／遥控／收听端，不是独立FMO上游电台客户端。1.0.13已在一块CH343实机与电脑合成源上完成冷／恢复／菜单／暖机、断供重连和长尾处理验证；未做人耳试听、DAC全样本采集或真实FMO互通，不能据此承诺真实服务完全复刻。

Beacon已有历史CH343配对的10轮前台生命周期和一次独立接收器RF数据证据；最新固件须重验，退出后的系统BLE头寸保护曾拒绝恢复。DMR 0.1.1按用户明确确认的范围交付连接测试版，仅展示受控连接／协议状态，不支持语音通话。AMBE实验服务默认关闭，语音功能留到后续单独验收；不得宣传为完整DMR对讲机。

历史modulo回退和图标内存压力属于整机UI门禁，由维护方在最终固件上验收；本SDK静态／主机通过不能代替该门禁。不能将旧固件上的通过条目自动继承给最终待发行固件，也不能把一项APP通过写成全部系统通过。

## AI工作流

保留现有一句话入口。BLE选ble，UDP／WS选net，PCM选stream，UTC选device；prepare会返回真实头文件和相关规则，不要求AI每次重读整套文档。新API使用须满足所选同发行SDK与目标固件门禁。AMBE不作为常规生成方案；不得用Opus／ADPCM替代后宣称DMR兼容。维护方发布前还要对齐API索引、快照、校验器、例子和服务端独立复验。

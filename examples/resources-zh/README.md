# 中文与资源背景

原创建模笔画组成“你好”，生成 240×240 RGB565LE 背景；包内资源不计入 WASM 静态数组。
资源已经随 SDK 附带，也可以 `python examples/resources-zh/generate_art.py` 重建。
应用仅保存三个绘图命令；底图由宿主按脏条带读取。上下选择 Exit，按中键退出。

`GFX_TEXT` 只支持 ASCII。不能把 UTF-8 字符串塞入它来显示中文；实际产品应使用已获授权字体离线生成字形，再局部 blit 或一次上传 A4 纹理。
清单中的中文包名称与界面中文字形是两件事；中文启动器名需按 manifest 文档提供已获授权的字体。

# 原生缓存 UI 模板

完整标题和三行菜单，A4 中文/英文纹理在初始化时只上传一次，共 4224 字节。
使用 8192 字节纹理预算、8 行 DMA、20ms 目标周期；这些不是实测 FPS。
稳定节点 ID 由原生缓动完成 160ms 选择变化。Pulse 改颜色，Slide 改位置，Exit 退出。
上/下选择，中键短按确认，左键立即返回应用列表；启动松手、去重和连翻由 product_input.h 处理。
首屏成功后 startup_ready 才返回 1；失败有界退出；shutdown 释放场景。
测试包括真实资源字节与 C 状态 fixture，不代表已执行设备渲染、I2S 或 C3 帧率验收。

# 异步 HTTP 模板

完整离线可见首屏先于网络启动；左键返回应用列表，启动键先松手。
使用保存的 Wi-Fi 与单个 HTTP_EX 请求，最多 1024 字节正文、4 秒请求截止时间和 15 秒总等待。
检查 phase、transport/native error、HTTP 状态、COMPLETE、返回长度和正文末尾 NUL。
公开示例地址可能返回超限正文；会明确报 HTTP/body error，不把截断内容当成功。
等待和失败状态仍可退出，退出后由宿主取消请求并释放会话；不关闭 TLS、不硬编码凭据。
状态轮询最多每 100ms，只有变化标签区域重绘。构建或桩测试通过不代表目标设备已联网。

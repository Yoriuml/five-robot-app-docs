# 异步 HTTP

使用设备已保存的 Wi-Fi，连接后请求公开的小文档。无账号、密钥或硬编码网络密码。
中键随时退出；启动按键先松开。状态最多每 100ms 轮询，15 秒停止等待，不无限重试。
未配置网络时提示先设置 Wi-Fi；不假装系统会替 APP 弹出配网页。TLS 验证保持开启。

示例展示状态/HTTP 错误流程，不保证目标响应永远小于 2048B。
产品可改用有明确响应上限的业务接口或 HTTP_EX 并按真实结构设置配额；不要关闭 TLS 来绕过错误。
联网应用静态内存上限 48KiB，系统 Wi-Fi/TLS 堆额外占用；本例构建成功不代表任何固件上的 HTTPS 都能成功。

# BLE 会话示例

SDK 2026.10.28.1，要求配套API2.16固件。发布状态以官方索引为准；旧API2.15固件不支持ble_open。
启动器显示“BLE应用”，复用已有许可的starter字形缓存，不在SDK中重复携带完整中文字体。新APP按工作流选择HarmonyOS Sans SC，不使用Noto Sans SC。

先绘制离线首屏，松开启动键后，中键开始/停止 STREAM GATT，左键停止并退出。
状态每200ms查询且只在变化时更新文字。完整配置只在开始时同步提交，异步后端不持有 APP 指针。
示例不同时开启 Wi-Fi，不修改音频，不模拟手机系统弹窗，不实现独立 Beacon。

完整结构见 [x622_ble_session.h](../../sdk/xapp/x622_ble_session.h)。HID、RECORDS 共享同一入口与停止/状态接口；选定角色后按真实头文件使用发送或记录读写操作。

启动和包检查只能证明相应主机路径；配对、订阅、重连、空口送达和实机 UI 流畅度还须目标设备验收。
